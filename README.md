# 🛡️ Wethaq (وثاق)
AI-powered research originality and IP-readiness assistant for student projects.

## 🚀 Overview
**Wethaq** is an intelligent graduation project assistant designed to help students analyze their research papers, evaluate originality, check similar literature via Crossref, and get a step-by-step readiness guide for intellectual property (IP) protection through the Saudi Authority for Intellectual Property (**SAIP**).

## ✨ Key Features
* **Dynamic PDF Parsing:** Automatically extracts Title, Abstract, Methodology, and Keywords using `pdfplumber`.
* **Smart Literature Search:** Connects with Crossref API to find similar academic papers and compute textual overlap.
* **Innovation Gap Analysis:** Compares project details with existing research to highlight unique contributions.
* **SAIP IP Readiness Guidance:** Generates a structured draft and compliance checklist for patent/IP applications in Saudi Arabia.

## 🛠️ Tech Stack
* Python
* Streamlit
* Pdfplumber
* Requests (Crossref API)
